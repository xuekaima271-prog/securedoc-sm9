# 6 系统测试

表 6.1 测试环境配置

功能测试以五组端到端场景为主干，每组场景从登录开始完整走通“签发—加密—上传—下载—解密—还原”链路，结果如表 6.2 所示。

表 6.2 端到端场景测试结果

| 场景 | 检查点数 | 结果 | 覆盖要点 |
|---|---|---|---|
| 基础闭环（alice→bob） | 15 | 全部通过 | 密钥初始化、加密投递、接收解密、字节级还原一致 |
| 新用户全流程 | 18 | 全部通过 | 管理员创建用户、KGC 身份登记、新用户首次签发与收发 |

## 6.3 安全性测试

针对第 3 章威胁模型逐项设计安全测试，结果如表 6.3 所示。

表 6.3 安全性测试结果

| 测试项 | 方法 | 预期与结果 |
|---|---|---|
| 非接收人解密 | 以正确身份串+他人私钥解封信封 | 解封失败，无法得到 DEK（通过） |
| 非接收人接口访问 | 非接收人请求他人文件分块 | 403 拒绝并记录 UNAUTHORIZED_FILE_ACCESS（通过） |
| 密文篡改 | 修改已存储分块字节后下载 | SM3 摘要失配，拒绝解密并记录 CHUNK_TAMPER_DETECTED（通过） |
| 越权调用 | 普通员工调用管理员/审计接口 | 统一 403，方法级与过滤器级均记录 ACCESS_DENIED（通过） |
| 口令暴力破解 | 连续错误口令登录 | 账号锁定，记录 BRUTE_FORCE_LOCK；单 IP 高频触发 IP_THROTTLED（通过） |
| 审计日志篡改 | 直接修改/删除 audit_logs 记录 | 链校验定位断点，记录 AUDIT_CHAIN_BROKEN（通过） |
| 伪造身份骗取私钥 | 以不匹配身份串请求签发 | KGC 拒绝（IDENTITY_MISMATCH）（通过） |
| KGC 未授权访问 | 缺失/错误服务令牌调用签发接口 | 401 拒绝（通过） |
| 服务端明文核查 | 检查数据库与对象存储全部字段 | 仅密文、密文摘要、加密元数据与信封，无明文（通过） |
| 超大分块 | 上传超过上限的分块 | 拒绝并记录 OVERSIZED_CHUNK（通过） |

值得说明的是，“正确身份串+错误私钥必须解封失败”这一强负例正是发现并修复 GmSSL-JS 机密性缺陷（5.1.2 节）的测试项，修复后该负例真实通过。

## 6.4 算法标准符合性测试

国密算法实现的正确性以标准测试向量逐字节比对验证，结果如表 6.4 所示。

表 6.4 标准符合性测试结果

| 对标项 | 基准来源 | 结果 |
|---|---|---|
| SM3 摘要（含多分块消息） | GB/T 32905—2016 标准向量 | 逐字节一致 |
| SM4 加解密 | GB/T 32907—2016 标准向量 | 逐字节一致 |
| SM9 用户私钥 de_B（128 B） | GmSSL 官方测试向量 | 逐字节一致 |
| SM9 封装 C1 横坐标（标准随机数 r） | SM9 标准示例数据 | 一致 |
| Java↔JavaScript 互通 | KGC 签发私钥供浏览器解封 | 双向一致 |

Java 与 JavaScript 两套实现（KGC 签发侧与浏览器加解密侧）对同一身份计算的 $H_1$、主公钥与用户私钥逐字节一致，保证了跨语言互操作的正确性。

## 6.5 性能测试

浏览器端密码运算与端到端投递性能实测结果如表 6.5 所示。

表 6.5 性能测试结果

| 指标 | 实测值 |
|---|---|
| SM9 密钥封装（冷启动首次） | 35.8 ms |
| SM9 密钥封装（热态平均） | 28.5 ms |
| SM9 密钥解封（平均） | 14.3 ms |
| KGC 私钥签发（keygen/extract，无配对） | 2.4 / 7.1 ms |
| SM4-CBC 加密吞吐（浏览器纯 JS） | 14.4 MB/s |
| SM3 摘要吞吐（浏览器纯 JS） | 45.8 MB/s |
| 50 MB 文件端到端加密（含分块与摘要） | 11.6 MB/s |
| 50 MB 文件下载+校验+解密 | 8.1 MB/s |

结果分析：（1）SM9 双线性对是最重的单次运算（约 30 ms），但混合加密架构下它只作用于 128 比特的 DEK，每位接收人仅一次封装，用户感知可忽略；文件本体由 SM4 承担，整体瓶颈在纯 JavaScript 对称运算吞吐。（2）50 MB 文件全流程（加密约 4.3 s、下载解密约 6.2 s）配合逐块进度条，满足 3.2 节“日常文档投递可接受等待”的需求。（3）KGC 侧签发不含配对运算，毫秒级完成，可支撑批量用户初始化。

## 6.6 本章小结

本章从功能、安全性、标准符合性与性能四个维度完成系统测试：128 项单元与集成测试及五组端到端场景全部通过，并在真实 MySQL 生产档复测；十项安全测试覆盖威胁模型全部条目，负例测试验证了加密与身份的真实绑定；SM3/SM4/SM9 实现命中国家标准与 GmSSL 官方向量；性能实测表明浏览器内国密端到端加密满足企业日常投递需求。测试结果完整支撑了第 1 章提出的设计目标。
