# 新疆科技学院本科毕业论文（设计）格式规范速查（2026版修订）

> 来源：《撰写规范（2026版修订）》+《打印格式要求》原文提炼。构建脚本 `scripts/build_thesis.py`
> 已自动实现绝大多数条目；本文件用于人工核对与回答格式问题。

## 1. 硬性指标

| 项 | 要求 |
|---|---|
| 字数 | 人文社科/医学 ≥8000；**理工类 ≥10000** |
| 题目 | 中文 ≤25 字；外文 ≤12 实词；避免生僻缩略词；可加副标题 |
| 中文摘要 | 300~500 字，第三人称，不用公式图表、不标引文编号；重点写结果与结论 |
| 关键词 | 3~5 个，分号分隔，外延大的在前，须在文中有明确出处 |
| 英文摘要 | 与中文对应，无语法/拼写错误 |
| 参考文献 | **≥13 篇，外文 ≥3 篇**，原则上近 5 年；只列正文直接引用的；一篇多处引用只出现一次（以首次为准） |
| 目录 | 编到三级标题，与正文标题一致 |

## 2. 页面与字体

- A4 单面（正文双面打印），横排不分栏；边距：上下 2.5cm、左右 3.0cm；页眉、页脚各 1.5cm。
- 中文一律宋体；阿拉伯数字与西文一律 Times New Roman。
- 行距：除页眉页脚和表格内容用单倍外，其余一律**多倍行距 1.3**。

## 3. 页眉页码

| 部分 | 页眉 | 页码 |
|---|---|---|
| 封面、扉页（声明） | 无 | 无 |
| 中/英文摘要 | 无 | 无 |
| 目录 | 无 | 罗马数字 Ⅰ、Ⅱ…（单独编） |
| 正文 | 奇数页=论文题目；偶数页=新疆科技学院本科毕业论文（设计）※ | 阿拉伯数字从 1 开始 |
| 结论 | 结  论 | 续排 |
| 参考文献 / 致谢 / 附录 | 参考文献 / 致  谢 / 附  录 | 续排 |

※ 毕业论文删"（设计）"，毕业设计删"论文"字样（构建脚本按 thesis.json 的 `doc_type` 处理）。
注意：旧模板奇偶页眉与 2026 规范文字相反，以 2026 规范为准。

## 4. 标题层级

| 级别 | 编号 | 字号字形 | 对齐 | 段前/段后 |
|---|---|---|---|---|
| 一级（章） | 1、2、3 | 小二号粗体 | 居中 | 0.5行/0.5行，**每章另起一页** |
| 二级（节） | 2.1 | 小三号粗体 | 顶格左对齐 | 0/0 |
| 三级 | 2.2.1 | 四号粗体 | 顶格左对齐 | 0/0 |
| 四级 | 2.2.1.1 | 小四号（不加粗） | 顶格左对齐 | 0/0 |

- 编号后**空两格**书写标题；标题 ≤15 字、**不得使用标点**；层次一般不超过四级，再往下用（1）（2）或①②③。
- 各级标题不得置于页面最后一行（孤行）。

## 5. 特殊标题（小三号粗体居中）

- 摘要："摘  要"，段前/段后各 0.5 行；摘要正文小四、首行缩进 2 字符、段前段后 0.5 行；正文后空一行写关键词，左顶格，"关键词："加粗。
- 英文摘要：英文题目小三居中在前，"ABSTRACT" 小三粗体居中；余同中文摘要，"Keywords:"加粗。
- 目录："目  录"，段前 1 行、段后 2 行；条目小四。
- 参考文献 / 致谢 / 附录：同目录标题；参考文献内容**五号、左顶格悬挂对齐**；致谢/附录内容小四。

## 6. 正文、图、表、公式

- 正文：小四，首行缩进 2 中文字符（本项目采用两端对齐）。
- 图：图序图题在图**下方**居中，五号；按章编号（图2.1），序后空两格；先见文后见图，插图不拆页、不跨节；引用他人图注明出处；分图用（a）（b）。
- 表：表序表题在表**上方**居中，五号；按章编号（表2.1）；采用国际通行**三线表**；表内文字五号，数据栏水平垂直居中，单倍行距；跨页时表头重复并右上写"续表××"。
- 公式：用 Word 公式编辑器（构建脚本从 LaTeX 自动转换为 OMML 原生公式）；按章编号（1.1）放行末最右端；公式首行缩进 5 字符，不居中；过长在 = 或运算符处转行，运算符置行首；变量斜体、矢量粗斜体、单位与常用函数正体；行文引用写"见公式1.1/由公式1.1"。
- 数字：用阿拉伯数字（GB/T15835-2011），年份写全（2003 年不写 03 年）。
- 量和单位：GB3100~3102；单位符号正体小写（人名单位首字母大写）；非物理量可用 元/km 形式。
- 注释：脚注或尾注；脚注不隔页。

## 7. 参考文献著录（GB/T 7714-2015）

序号 `[1]` 与正文引用一致。常用类型格式：

| 类型 | 格式 |
|---|---|
| 图书 M | [1]作者.题名[M].出版地:出版者,年:起止页. |
| 学位论文 D | [2]作者.题名[D].保存地:保存单位,年. |
| 会议文集 C | [3]作者.题名:论文集名[C].出版地:出版者,年. |
| 析出文献 C// | [7]作者.题名[C]//论文集名.出版地:出版者,年:起止页. |
| 期刊 J | [8]作者.题名[J].刊名,年,卷(期):起止页. |
| 标准 S | [5]发布者.标准号 标准名[S].出版地:出版者,年. |
| 报告 R | [4]作者.题名[R].报告地:主办单位,年. |
| 报纸 N | [9]作者.题名[N].报名,年-月-日(版次). |
| 专利 P | [10]专利所有者.题名:专利号[P].公告日期. |
| 电子文献 EB/OL | [11]作者.题名[EB/OL].(更新日期)[引用日期].URL. |

外国著者：姓前名后、姓全大写缩写（如 COHN-GORDON K）；3 人以上加"等/et al"。

## 8. 装订顺序与打印

封面 → 扉页（写作声明和使用授权说明，**黑色签字笔手写签名**）→ 中文摘要 → 英文摘要 → 目录 → 正文（从绪论至附录，双面打印，每章另起一页）→ 参考文献 → 致谢 → 附录。左侧装订。
封面/声明/摘要/目录单面打印；中文摘要原则上控制在一页。
